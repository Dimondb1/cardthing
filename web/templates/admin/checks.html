Claude settles every row itself. When it is sure or fairly sure and the site's rules agree, it acts. When it still cannot tell after a careful second look, it takes the safe choice: a doubtful price stays as shown with no saving claimed, a found page is not compared, the cheaper price of a wrong match is hidden, and a pair is kept apart for now and asked about again when anything about it changes. A pair is never merged on a doubt.
